- Fork this repository
- Install [xLights](https://xlights.org/)
- Open xLights and set your show directory to point [here](./shows/sign-rev-1)
- For an example, load a sequence from [here](./shows/sign-rev-1/sequences)
- Make your own sequence as a candidate for display
- Start an issue if you run into problems
- Open a Pull Request that adds your xsq to
  [./shows/sign-rev-1/sequences](./shows/sign-rev-1/sequences) and adds a
  note in the list of [sequences](./sequences.md)
