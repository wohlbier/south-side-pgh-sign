# Program the sign!
- Fork this repository and clone your fork
- Install [xLights](https://xlights.org/)
- Open xLights and set your show directory to point [shows/sign-rev-1](./shows/sign-rev-1)
- For an example, load a sequence from [shows/sign-rev-1/sequences](./shows/sign-rev-1/sequences)
- Make your own sequence as a candidate for display
- Start a github [issue](https://github.com/wohlbier/south-side-pgh-sign/issues)
  if you run into problems
- Open a Pull Request that adds your `xsq` file to
  [shows/sign-rev-1/sequences](./shows/sign-rev-1/sequences) and adds a
  note in the list of [sequences](./sequences.md) and an animation in
  [docs/sequences/](./docs/sequences)
